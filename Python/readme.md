# Python Automation Toolkit

A collection of Python automation utilities, web scraping scripts, and system tools built for experimentation and personal productivity.

## Features

* Web scraping utilities
* Wallpaper automation
* PowerShell loader scripts
* Browser and website automation
* Data extraction tools
* Custom workflow automation

## Project Structure

```text
.
├── dd/
├── live_wallpaper.py      # Wallpaper automation utility
├── loader.ps1             # PowerShell loader script
├── script.py              # Main automation script
├── shop_scraper.py        # Website/product scraping utility
├── wa (1).py              # Additional automation tool
└── readme.md
```

## Requirements

* Python 3.10+
* pip
* Windows 10/11 (recommended)

Install dependencies:

```bash
pip install -r requirements.txt
```

If no requirements file exists, install the libraries used by the scripts manually.

## Usage

Run any script directly:

```bash
python script.py
```

Example:

```bash
python shop_scraper.py
```

or

```bash
python live_wallpaper.py
```
